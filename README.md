# MY-AGENTS

个人常用 AI Agent 资源库，用来集中保存可复用的技能说明及其配套文件，方便查找、安装和维护。

## 资源目录

| 路径 | 内容 |
| --- | --- |
| [`SKILL/`](SKILL/) | Agent Skills 资源目录。每个技能单独放在一个子目录中。 |
| [`SKILL/README.md`](SKILL/README.md) | 技能目录说明、收录约定和 Codex 安装方法。 |

## 当前收录

- [`ui-polish`](SKILL/ui-polish/SKILL.md)：检查并改进网站或前端界面的视觉质量，包含一份配套的视觉检查清单。

## 使用

先阅读 [`SKILL/README.md`](SKILL/README.md)，按需将某个技能安装到 Codex 或其他 Agent 能发现的技能目录。安装前请先检查技能说明及其脚本，因为技能内容会影响 Agent 的执行方式。

## 收录约定

- 一个技能一个目录，目录内以 `SKILL.md` 作为入口。
- 参考资料、脚本、模板等配套文件与所属技能放在同一目录中。
- 保留技能所需的目录结构，并在 README 中维护资源索引和安装说明。
